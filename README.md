# PackageRadar – סקריפטים ל-Tampermonkey

מאגר זה מרכז שני סקריפטים נפרדים לשימוש באתר [PackageRadar](https://packageradar.com/).

## 1. חיפוש ישיר – דילוג על חלונית השדרוג

**קובץ:** \`packageradar-direct-search.user.js\`  
**גרסה:** 2.4

הסקריפט מאפשר להמשיך בחיפוש חבילות בלי לעצור ידנית בחלונית ההצעה לשדרוג.

### מה הוא עושה?

- מזהה חיפוש באמצעות לחיצה על כפתור החיפוש או שליחת הטופס באמצעות Enter.
- ממתין לחלונית השדרוג ומאתר את כפתור הסירוב שלה.
- לוחץ פעם אחת על כפתור הסירוב ומוודא לאחר מכן אם החלונית נסגרה.
- תומך בעמוד הראשי ובעמוד "החבילות שלי".
- מתחשב בשינויים ב-DOM שנוצרים בעקבות Google Translate.
- אינו מסתיר או משנה את עיצוב החלונית באמצעות CSS, כדי לא להפריע למנגנון האתר.
- מדפיס הודעות אבחון ב-Console עם הקידומת \`[PackageRadar]\`.

### התקנה

1. ודאו שתוסף [Tampermonkey](https://www.tampermonkey.net/) מותקן בדפדפן.
2. פתחו את [קובץ הסקריפט להתקנה](https://raw.githubusercontent.com/HAKOL-MILEMALA/packageradar-smart-refresh/main/packageradar-direct-search.user.js).
3. בחלון Tampermonkey לחצו על **Install**.

## 2. רענון חכם – עמוד "החבילות שלי"

**קובץ:** \`רענון-חכם.user.js\`  
**גרסה:** 1.4

מוסיף לעמוד החבילות כפתור לרענון מרוכז של חבילות, בקבוצות, עם השהיה בין הקבוצות והודעות אבחון ב-Console.

### התקנה

1. ודאו שתוסף [Tampermonkey](https://www.tampermonkey.net/) מותקן בדפדפן.
2. פתחו את [קובץ הסקריפט להתקנה](https://github.com/HAKOL-MILEMALA/packageradar-smart-refresh/raw/refs/heads/main/%D7%A8%D7%A2%D7%A0%D7%95%D7%9F-%D7%97%D7%9B%D7%9D.user.js).
3. בחלון Tampermonkey לחצו על **Install**.

## עדכונים אוטומטיים

שני הסקריפטים כוללים את המטא-נתונים \`@updateURL\` ו-\`@downloadURL\` שמפנים לקובץ המתאים במאגר GitHub.

לאחר התקנה דרך הקישורים לעיל, Tampermonkey יכול לבדוק עדכונים ולהוריד גרסאות חדשות מאותו קובץ. אין צורך להתקין מחדש בכל עדכון גרסה.

כדי לפרסם עדכון בעתיד:
1. מעלים את הגרסה החדשה לאותו נתיב קובץ במאגר.
2. מעלים את מספר \`@version\` בכותרת הסקריפט.
3. משאירים את כתובות \`@updateURL\` ו-\`@downloadURL\` ללא שינוי.

> שימו לב: עדכונים אוטומטיים פועלים עבור התקנות שמקורן בקישורים הקבועים שבמאגר. אם Tampermonkey מציע עדכון, יש לאשר אותו בהתאם להגדרות העדכון שלכם.
